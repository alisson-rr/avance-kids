## Sheet: Instruções
| Como preencher esta planilha |
| --- |
| Há duas abas para preencher: Perguntas e Atividades. Preencha só o que for enviar — uma aba vazia é ignorada. |
| Apague as linhas de exemplo antes de enviar. Elas estão marcadas na primeira coluna. |
| Não mude, não traduza e não reordene os títulos das colunas: a importação confere um por um e para se algum estiver diferente. |
| Aba PERGUNTAS |
| Tipo: 'Inicial' para as perguntas de pré-requisito da faixa; 'Triagem' para as perguntas de cada habilidade. |
| Faixa: o código da faixa etária (ver tabela abaixo). |
| Habilidade: uma das cinco. Toda pergunta precisa de uma, inclusive as do tipo Inicial. |
| Ordem: a sequência em que a pergunta aparece. Números inteiros, sem repetir dentro da mesma combinação de Tipo + Faixa + Habilidade. |
| Pergunta: o texto exato que o responsável vai ler. |
| Importante: as perguntas do tipo Inicial são as que decidem se a criança começa numa faixa mais baixa — duas respostas 'quase nunca' rebaixam uma faixa. Por isso vale manter a mesma quantidade de perguntas Inicial em todas as faixas. |
| Aba ATIVIDADES |
| É o mesmo formato de 17 colunas da planilha que você já enviou. Se for atualizar aquele arquivo, pode enviá-lo direto: não precisa recopiar para cá. |
| Cada código precisa de exatamente 3 linhas, uma para cada Nível (Aquisição, Generalização, Manutenção). |
| Código: a faixa, a letra da habilidade e o número sequencial, sem espaços — por exemplo F01AC001. A letra de cada habilidade está na tabela abaixo. |
| Nenhuma célula pode ficar vazia nas 17 colunas. |
| O que NÃO vai nesta planilha |
| Imagem ou vídeo da atividade, marcação de Gratuito/Premium e arquivar/reativar são definidos no painel administrativo, atividade por atividade. Ficam de fora daqui para não haver dois lugares dizendo coisas diferentes sobre o mesmo item. |
| Faixas etárias |
| F01A — 12 a 24 meses |
| F02A — 25 a 36 meses |
| F03A — 37 a 48 meses |
| F04A — 49 a 60 meses |
| F05A — 5 a 7 anos (61 a 95 meses) |
| F06A — 8 a 11 anos (96 a 143 meses) |
| Habilidades e a letra usada no código |
| C — Comunicação |
| S — Social |
| G — Cognitiva |
| M — Coordenação Motora |
| F — Funcional |
